# Financeiro Pessoal 360 — Windows

Downloads oficiais do aplicativo desktop do Financeiro Pessoal 360.

## Baixar

Abra a [versão mais recente](https://github.com/leonardourbinatinog-spec/financeiro-pessoal-360-desktop/releases/latest) e escolha:

- **`Financeiro-Pessoal-360-<versão>-Instalador.exe`**: instala o aplicativo com atalhos no menu Iniciar e na área de trabalho.
- **`Financeiro-Pessoal-360-<versão>-Portatil.exe`**: roda sem instalar.

Os dois usam a mesma pasta de dados (`%APPDATA%\Financeiro Pessoal 360`), que é preservada nas atualizações e na desinstalação. Confira os arquivos com o `SHA256SUMS.txt` de cada versão.

Os executáveis ainda não têm assinatura por certificado, então o Windows pode exibir um aviso do SmartScreen ao abrir.

## Atualizações

A partir da versão 1.1.0, o aplicativo avisa quando há uma nova versão e permite baixar e instalar, lembrar mais tarde ou pular a versão. O `atualizacao.json` de cada versão é assinado; o aplicativo recusa arquivos que não correspondam à versão publicada. Quem usa a 1.0.0 precisa instalar a 1.1.0 manualmente uma única vez.

Este repositório contém apenas os arquivos de distribuição.
